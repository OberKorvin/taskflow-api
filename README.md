# 🚀 TaskFlow API

A RESTful API for task management built with Python, FastAPI, and SQLAlchemy (SQLite).

## ✨ Features
- Full CRUD: Create, read, update, and delete tasks.
- Persistent Storage: Relational database integration via SQLAlchemy ORM.
- Search & Filtering: Filter tasks by completion status and search by title keywords.
- Sorting & Analytics: Order tasks from newest to oldest and retrieve real-time task statistics.
- Data Validation: Strict request validation using Pydantic schemas.

## 🛠 Tech Stack
- Python 3.12
- FastAPI & Uvicorn
- SQLAlchemy (SQLite)
- Pydantic
